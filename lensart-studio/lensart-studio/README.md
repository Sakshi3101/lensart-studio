# LensArt Studio — Modular Version

Same design and behaviour as the original single `photography_studio.html`, split by **type** (html / css / js / assets) and by **module** (nav, hero, portfolio, …).

## Run it
Double-click **`index.html`** — no server needed.

## Real photos (important)
The original page loaded its 20 photos from Unsplash. This package ships **placeholder images** at the same paths so the layout works offline. To get the real photos, run once (needs internet):

```
python download_images.py
```

Or just drop your own photos over the files in `assets/images/` (same filenames).

## Folder structure

```
lensart-studio/
├── index.html              ← ready-to-open page (generated by build.py)
├── build.py                ← rebuilds index.html from the partials
├── download_images.py      ← fetches the original Unsplash photos
├── html/                   ← one partial per module
│   ├── navbar  hero  stats  portfolio  packages  wedding
│   ├── process  testimonials  about  contact  footer
│   └── login-modal  register-modal  lightbox  toast
├── css/                    ← one stylesheet per module
│   ├── base.css            (variables, reset, common section styles, animations)
│   ├── nav  hero  stats  portfolio  packages  wedding  process
│   ├── testimonials  about  contact  footer  modal  toast  lightbox
│   └── responsive.css      (media queries — loaded last)
├── js/                     ← one script per feature
│   ├── toast  hero-slider  modal  auth  contact-form  lightbox
│   └── gallery-filter  scroll-reveal  skill-bars  counters  nav
└── assets/
    ├── images/  hero/ portfolio/ wedding/ testimonials/ about/ contact/  (+ manifest.json)
    ├── icons/     SVG icons (packages, contact, social) + favicon.svg
    ├── stickers/  camera, heart, award-badge, sparkle-burst (SVG, not placed on the page yet)
    └── videos/    empty — the original page has no video
```

## Editing workflow
1. Edit a module, e.g. `html/packages.html` and `css/packages.css`.
2. Run `python build.py` to regenerate `index.html`.
   (Or edit `index.html` directly if you prefer — but then `html/` won't match.)

To add a module: create `html/<name>.html`, `css/<name>.css`, `js/<name>.js` and add the name to the lists at the top of `build.py`.

## Notes
- Paths inside `html/*.html` are relative to the project root (where `index.html` lives), because the partials are merged into that file.
- Fonts (Cormorant Garamond, Bebas Neue, Montserrat) still load from Google Fonts, so they need internet. To self-host, download them and add `@font-face` rules to `css/base.css`.
- Compared with the original, the emoji icons (💍 👑 🎉 🏢 👤 ✨ 📍 📞 ✉️ 🕐 and the social buttons) are now SVG files in `assets/icons/`. A favicon was added. Everything else is unchanged.
